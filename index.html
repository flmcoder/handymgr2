v9.2.6

          

          
CSS variable audit
All hardcoded hex/rgb colors in .refresh-btn, .sec-refresh, vendor cross-nav, pipe-card, radar-badge replaced with CSS custom properties for consistent theming.

          
Dark mode dim variables
Added missing --danger-dim, --success-dim, --info-dim, --warning-dim, --purple-dim overrides in html.dark block.

          
Section nesting fix
Fixed sec-properties being nested inside sec-billing table-wrapper — properties section now renders independently.

          
Properties table scroll
Properties table wrapper changed from undefined .table-responsive to .table-scroll class for proper horizontal overflow on mobile.

          

        

        

          
v9.2.4

          

          
Unit tracking
Units are now cached from AppFolio (/api/v0/units) and linked to properties. The Properties panel shows unit counts per property.

          
Property detail — Units tab
Property detail modal now shows a Units tab with status (Occupied/Vacant/Notice), bed/bath, and a per-unit Bills filter shortcut.

          
Billing unit scope
Billing view now supports unit-level drill-down for multifamily. Scope chip shows Property › Unit with individual Clear Unit / Clear All buttons.

          
billing_map unit_id
Bills are now stored with unit_id in billing_map. bills_by_unit route added to proxy for server-side unit-scoped bill queries.
