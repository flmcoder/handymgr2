Best Practices

Troubleshooting
When troubleshooting issues associated with the AppFolio Reports API, ensure you can answer Yes to
the following questions in the checklist. If you answer No to any of the following questions, it is likely
that you have found the problem.
api docs by redocly
1. Is the URL correct?
A valid URL should look similar to https://vhost.appfolio.com/api/v2/reports/{endpoint}.
2. Were the correct credentials passed in the request?
We strongly recommend ensuring the correct credentials were passed in the initial request.
3. Is the authorization header valid?
Ensure the formatting of the Client ID and Client Secret passed into your authorization header are valid.
5. Are the request parameters valid?

If an incorrect parameter value was passed, the returned error codes should be descriptive enough to
assist you in identifying the problem.
6. Is the rate at which you are issuing requests regulated?
In general, staggering the rate at which you issue requests will prevent network congestion and errors.
